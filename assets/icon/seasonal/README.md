# Сезонные иконки

Иконки приложения под каждое время года — пока не подключены, лежат про запас.

| Файл | Сезон |
|---|---|
| `spring.png` | Весна |
| `summer.png` | Лето |
| `autumn.png` | Осень |
| `winter.png` | Зима и Новый год |
| `_source_sheet.webp` | Исходный лист со всеми четырьмя, как пришёл |

Вырезаны из общего листа: тёмный фон вокруг скругления убран в прозрачность,
края восстановлены без тёмной каймы.

**Разрешение ~375×375** — для иконки на рабочем столе маловато: адаптивная
иконка Android на экранах высокой плотности берёт 432×432, и при растягивании
станет мягкой. Перед подключением стоит получить каждую отдельно в 1024×1024.

Нынешняя иконка приложения — `../app_icon.png`, осенняя, того же стиля.

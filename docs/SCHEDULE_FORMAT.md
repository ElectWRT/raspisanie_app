# Формат импорта расписания (.md)

Приложение читает основное расписание из обычного текстового файла Markdown.
Формат выбран так, чтобы его было легко и написать руками, и получить от
нейросети по промпту (он лежит в приложении: **Настройки → Формат файла и промпт**,
кнопка «Скопировать промпт»).

Готовый пример — [`samples/schedule_example.md`](../samples/schedule_example.md).

## Структура

```markdown
# Звонки (пн-пт)
1. 08:30 - 10:00
2. 10:10 - 11:40

# Звонки (сб)
1. 08:30 - 09:30
2. 09:40 - 10:40

# СА-2124

## Понедельник
1. Компьютерные сети | Иванов И.И. | 301
2. (числ) Математика | Петрова А.А. | 210
2. (знам) Физика | Кузнецов В.В. | 112
3. [1] Английский язык | Смирнова О.П. | 208
3. [2] Английский язык | Волкова Н.С. | 209

## Вторник
1. Операционные системы | Петров П.П. | 305
```

| Элемент | Что значит |
| --- | --- |
| `# СА-2124` | Заголовок первого уровня — название группы. Всё ниже относится к ней, пока не встретится следующий заголовок группы. В одном файле можно описать сколько угодно групп. |
| `# Звонки` | Особый заголовок: блок со временем пар. Может стоять в любом месте файла. |
| `# Звонки (сб)` | Набор звонков для конкретных дней. Понимаются диапазоны (`пн-пт`), перечисления (`пн, ср, пт`), полные названия и падежи (`на субботу`). Набор без дней в заголовке — основной, он применяется ко всем дням, для которых своего набора нет. |
| `## Понедельник` | День недели. Понимаются полные названия и сокращения: `Пн`, `Вт`, `Ср`, `Чт`, `Пт`, `Сб`, `Вс`. Регистр и хвост вроде `## Понедельник (числитель)` не мешают. |
| `1. Предмет \| Преподаватель \| Аудитория` | Пара. Номер обязателен, разделитель — вертикальная черта. Преподавателя и аудиторию можно не указывать. Вместо точки после номера допустимы `)`, `-`, `:`. |
| `(числ)` / `(знам)` | Пара идёт только на числителе или только на знаменателе. Без маркера — каждую неделю. Синонимы: `(ч)`, `(з)`, `(верх)`, `(нижн)`. |
| `[1]` / `[2]` | Пара только для этой подгруппы. Синоним: `(1 п/г)`. |

Маркеры можно совмещать в любом порядке:
`2. (числ) [1] Английский | Смирнова О.П. | 208`

## Мелочи, которые парсер прощает

* Пустые строки, горизонтальные линии `---`, блоки кode ``` — игнорируются.
* Дни без пар можно просто не писать. Строки `нет пар`, `выходной`, `-`
  тоже не считаются ошибкой.
* Строки Markdown-таблиц разбираются: `| 1 | Сети | Иванов И.И. | 301 |`
  читается как `1. Сети | Иванов И.И. | 301`.
* Всё, что парсер не понял, попадает в список предупреждений на экране
  предпросмотра — строки не теряются молча.

## Что происходит при импорте

Импорт **перезаписывает пары только тех групп, которые есть в файле**.
Расписание остальных групп остаётся нетронутым — можно заливать файлы по одной
группе. Блоки `# Звонки`, если они есть, заменяют ранее сохранённые звонки
целиком. Звонки можно править и вручную: **Настройки → Расписание звонков**.

Файл должен быть в кодировке **UTF-8**.
